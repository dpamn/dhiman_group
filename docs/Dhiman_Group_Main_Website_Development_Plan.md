# Dhiman Group -- Main Website Development Plan

## Project Goal

Build a clean, premium, corporate website for **Dhiman Group**.

### Website Purpose

-   Represent Dhiman Group as the parent company.
-   Introduce the group's business divisions.
-   Build trust and brand identity.
-   Direct visitors to the appropriate company.
-   Keep the experience simple, modern, and user-friendly.

------------------------------------------------------------------------

# Tech Stack

-   Next.js (App Router)
-   TypeScript
-   Tailwind CSS
-   Framer Motion
-   Lucide React
-   SEO Optimized
-   Mobile First

------------------------------------------------------------------------

# Design Principles

-   Keep it simple.
-   Avoid clutter.
-   No product listings on the group homepage.
-   Focus on branding and navigation.
-   Mobile-first responsive design.
-   Fast loading and SEO friendly.
-   Use reusable components.
